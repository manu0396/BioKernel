## Pilot Readiness Decisions

- Identity provider, issuer, client, audience, role mapping, and test accounts: **BLOCKED**; `.env.example` leaves OIDC values blank and no pilot issuer/client/test account was provided.
- Android client handset: Motorola Moto G55 5G, Android 16/API 36, security patch 2026-09-01; app install, launch, demo-session entry, and all 7 Android instrumentation tests passed on the handset. This is app-client evidence only. **Lab device/gateway model, firmware, tier, gateway version, TLS mode, and test owner remain BLOCKED**.
- End-to-end run ID/job ID mapping and source of truth: **GAP FOUND**; HTTP/gRPC run start stores a run in `RegenOpsInMemoryStore`; gateway publishes telemetry independently using `SIM_RUN_ID`. No start-command handoff ties these paths together.
- Android/desktop HTTP and gRPC hosts/ports: HTTP emulator default `10.0.2.2:8080`; desktop HTTP default `localhost:8080`; core/gateway gRPC default `9090`. Android gRPC default was inconsistent at `50051` and is corrected to `9090` in `apps/control-kmp/androidApp/build.gradle.kts`.
- Canonical Compose environment-file location: root `.env`, referenced from `ops/docker-compose.yml` as `../.env`; service build context is repository root (`..`). Config syntax/interpolation validated using `.env.example`; actual secret-bearing `.env` is absent.
- Telemetry cadence and stale-data threshold: **BLOCKED**; pilot owner/device measurements required before selecting a numeric threshold.
- Exact Android/desktop build, test, and packaging tasks: root `./gradlew test --no-daemon`; Android `:apps:control-kmp:androidApp:assembleDemoGoogleDebug`, `:apps:control-kmp:androidApp:connectedDemoGoogleDebugAndroidTest`; shared `:apps:control-kmp:shared:allTests`; desktop `:apps:control-kmp:desktopApp:test`, `:apps:control-kmp:desktopApp:run`, `:apps:control-kmp:desktopApp:packageDmg`; core `:services:core-server:test`; gateway `:agents:device-gateway:test`.
- Virtual-device result: `Medium_Phone` API 36 has sufficient storage; all 7 instrumentation tests pass with `./gradlew :apps:control-kmp:androidApp:connectedDemoGoogleDebugAndroidTest -PDEMO_MODE=true --rerun-tasks --no-daemon --console=plain`. Forcing task execution is required because Gradle does not track the environment/property value used to generate `BuildConfig`.
- Physical Android result: the same 7 instrumentation tests passed on the connected Moto G55 5G and the AVD; the demo app was installed/launched on the Moto, and the UI exposed `Enter Demo Session` and then `DEMO SESSION - NOT AUTHENTICATED`. `-Pandroid.injected.device.serial` did not narrow the connected-test task; both connected devices ran the suite.
- Post-change test result: `:apps:control-kmp:shared:allTests` and root `test` passed after correcting the Excel test's legacy unit/header expectations and making the JVM telemetry test stream replay its test frame. Focused `OidcRepositoryTest` also passes its authorization, token, pending, and denial cases.
- Focused module verification after removing duplicate source roots: mock-backed `:services:core-server:test` and `:agents:device-gateway:test` passed; desktop `compileKotlin` passed and its `test` task has no source tests. Android demo instrumentation passed 7/7 on both `Medium_Phone` API 36 and the physical Moto G55 5G after extending a slow-device UI wait. These checks are synthetic/app-client evidence, not connected lab-device acceptance.
- Android Studio duplicate-root warning: removed gateway main/test `srcDir` injection from `services/core-server` and replaced 14 manually shared KMP source roots with declared project dependencies in `apps/control-kmp/shared`. The previous IDE log also lists four generated `debugAssetsCopyForAGP` roots; these are Gradle-generated. Sync the Gradle project in Android Studio to refresh its model and confirm the source-root warnings have cleared.
- Accessibility/localization pilot requirements: not provided; confirm with pilot owner before usability acceptance.
- Remaining blockers and accountable owner: pilot owner must supply identity-provider configuration/test accounts, named physical device/gateway, and telemetry cadence/freshness threshold; no named owner identified.
